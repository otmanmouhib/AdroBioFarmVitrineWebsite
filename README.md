# ADRO BIO FARM Website

Un site Next.js pour la coopérative ADRO BIO FARM : ferme pédagogique, produits bio, hébergement, formations et résidence artistique.

## Installation

```bash
npm install
npm run dev
```

## Démarrage

- Ouvrez `http://localhost:3000`
- Le site utilise l’App Router de Next.js avec TypeScript et CSS global.

## Structure

- `app/page.tsx` : page d’accueil
- `app/products/page.tsx` : page des produits à vendre
- `app/services/page.tsx` : page des services et solutions durables
- `app/contact/page.tsx` : page de contact
- `app/layout.tsx` : structure principale avec navigation
- `app/globals.css` : styles modernes et mobile-first

## Personnalisation

Mettez à jour les textes, les coordonnées et les liens dans les fichiers de page de `app` pour refléter votre coopérative.
